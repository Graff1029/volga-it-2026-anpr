**Источники и происхождение версии 0.1**

При подготовке стартового проекта использовались инструменты автоматической генерации кода. Участнику нужно проверить и понимать код перед включением в конкурсную работу. Ограничение на долю автоматически подготовленного кода для текущего этапа пока не подтверждено; правила финала 2025 не объявляются действующими в полуфинале 2026.

Детектор: [morsetechlab/yolov11-license-plate-detection](https://huggingface.co/morsetechlab/yolov11-license-plate-detection), `license-plate-finetune-v1n.onnx`, ревизия `251a30d7daedca065f56e04b0af04052c907c68f`. Заявленная автором лицензия — AGPL-3.0. Карточка модели и текст лицензии сохранены рядом с весами. Автор указывает на пересечение исходных обучающей и тестовой выборок, поэтому его опубликованные метрики не используются как доказательство качества. Исходные изображения того датасета в наш набор не включены.

Распознавание: [JaidedAI/EasyOCR](https://github.com/JaidedAI/EasyOCR), версия 1.7.2, модель `english_g2` из официального релиза v1.3. Лицензия проекта — Apache-2.0. URL и проверка исходного MD5 определены в конфигурации EasyOCR; SHA-256 полученных весов записан в `models/manifest.json`. Условия проекта не означают, что любые чужие обучающие изображения можно включить в наш CC BY-датасет.

Библиотеки устанавливаются из их официальных пакетов; сведения о версиях фиксируются при установке. Собственные данные будут иметь отдельный реестр источников. Датасет сейчас пуст, лицензия CC BY 4.0 не присваивается неизвестным чужим изображениям.

Для распространения итоговой сборки необходимо сохранить лицензии и предоставить соответствующие исходники зависимых компонентов по их условиям. Готовые веса этого прототипа не выдаются за обученные участником. Собственный код передаётся участнику без добавления отдельного ограничения на использование; права и условия сторонних компонентов остаются у их авторов.
