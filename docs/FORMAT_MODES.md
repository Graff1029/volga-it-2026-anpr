# Формат номера по official README и validator

## strict — конкурсный режим по умолчанию

`strict` следует фактическим маскам из official README и `validate_dataset.py`:

- `type1`, `type1a`: `LDDDLLRR` или `LDDDLLRRR` (`A123BC77`, `A123BC778`);
- `type1b`: `LLDDDRR` или `LLDDDRRR` (`HY70477`, `HY704778`).

`L` — только латинская буква из `A B E K M H O P C T Y X`, `D` — цифра,
`#` допустим в позиции соответствующего неизвестного символа. Регион обязателен
и имеет две или три цифры без ограничения первой цифры: `323`, `550` и `778`
равноправны. Нормализация может исправить только типичное OCR-смешение
кириллицы/латиницы или буквы/цифры в уже предусмотренной позиции; она не
добавляет и не удаляет символы.

```powershell
.\run_submission.cmd C:\plates C:\result.csv
```

## extended — совместимое имя параметра

`--format-mode extended` оставлен для старых команд, но теперь применяет те же
official masks. Он не является отдельным разрешением для жёлтых номеров и не
ослабляет правила `type1`/`type1a`.

`lint_dataset.py` — локальная предварительная проверка; официальный
`validate_dataset.py` хранится отдельно в `evaluation/official_debug/extracted/`
и не был переименован или изменён.
