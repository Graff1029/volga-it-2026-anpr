# Источники изображений для пробной проверки Volga IT

Этот файл нужно положить в основную папку проекта, рядом с `predict.py`.
Файл `input_images/README.txt` содержит инструкцию к папке; заполнять его не нужно.

## Выбранный внешний набор

- Название: Russian License Plates Detector.
- Публикатор набора: RU ANRP на Roboflow Universe. Это имя публикатора набора, а не подтверждённое имя автора каждой фотографии.
- Версия: v3, «bbox annotation», опубликована 26 октября 2023 года.
- Страница: https://universe.roboflow.com/ru-anrp/russian-license-plates-detector/dataset/3
- Лицензия, указанная публикатором на странице: CC BY 4.0.
- Условия лицензии: https://creativecommons.org/licenses/by/4.0/
- Дата проверки страницы: 16 сентября 2026 года.
- Дата скачивания пользователем: не зафиксирована.

При распространении материала по CC BY 4.0 сохраняют предусмотренные лицензией сведения об авторстве и уведомления, ссылку на источник и лицензию, а также указывают изменения.

## Статус этих изображений в проекте

15 изображений использованы участником для пробного запуска программы. Имена ниже взяты из присланного отчёта `debug.json`. Связь с указанным набором записана по контексту выбора источника; исходный архив Roboflow и его README в этой передаче отсутствуют, поэтому происхождение каждого файла отдельно не подтверждено.

Назначение этой подборки — разбор ошибок. Это не официальный отладочный набор организатора и не готовый набор для конкурсной сдачи. После использования снимков для выбора изменений алгоритма они становятся материалом для разработки; для независимой оценки понадобится другая подборка.

На части фотографий видны водяные знаки PlatesMania и Avito. Надпись CC BY 4.0 в карточке набора сама по себе не подтверждает, что публикатор получил права от авторов всех фотографий. Право включать эти снимки в публикуемый конкурсный датасет пока не подтверждено. Этот файл фиксирует сведения об источнике и не заменяет разрешение правообладателя.

## Что сохранить из скачанного архива

Оставить оригинальные файлы README и LICENSE, если они входят в архив: например, `README.dataset.txt`, `README.roboflow.txt`, `LICENSE`. Их не нужно переписывать. Не удалять уведомления об авторах и правах.

Если появятся новые фотографии из другого источника, добавить отдельную запись: название, публикатор, ссылка, версия, заявленная лицензия, связанные имена файлов и сделанные изменения.

## Изменения изображений

Известно, что фотографии вставлены пользователем в Word для передачи на проверку. Сведения о других изменениях исходных JPG, а также об изменении их качества при вставке в Word отсутствуют. Поэтому извлечённые из документа изображения нельзя автоматически считать побайтовыми копиями файлов на компьютере участника.
