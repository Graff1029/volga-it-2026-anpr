# Волга IT 2026 Искусственный интеллект

Проект распознаёт российские автомобильные номера на изображениях и формирует
CSV для пакетной обработки. Репозиторий содержит исходный код, генератор,
скрипты подготовки и обучения, конфигурации и документацию.

Полная конкурсная сборка содержит веса и датасет и будет доступна отдельной
ссылкой. **Ссылка будет добавлена перед сдачей.**

## 1 Назначение

Входом служит каталог JPG или PNG. Программа находит номерные таблички,
определяет тип и распознаёт полный номер вместе с регионом. Результат
сохраняется в UTF-8 CSV.

## 2 Поддерживаемые типы номеров

- `type1`: одна буква, три цифры, две буквы, регион из 2 или 3 цифр.
- `type1a`: двухстрочный номер того же символьного формата.
- `type1b`: две буквы, три цифры, регион из 2 или 3 цифр.
- `other`: номер вне поддерживаемых форматов или вне транспортного средства.

Используется официальный латинский алфавит `ABEKMHOPCTYX`. Режим `strict`
является основным: строка не дополняется и не сокращается для прохождения
маски.

## 3 Архитектура pipeline

1. ONNX-детектор находит номерные таблички.
2. Эвристика геометрии определяет тип таблички и подготавливает crop.
3. EasyOCR читает строку или поля двухстрочного номера.
4. Нормализация и строгая проверка формата формируют итоговый CSV.

Во время распознавания используются только локальные файлы; загрузка моделей
из сети отключена.

## 4 Установка

Нужен Python 3.12 x64. Создайте окружение и установите зависимости:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для запуска нужны локальные файлы весов: ONNX-детектор,
`english_g2.pth` EasyOCR и выбранный OCR checkpoint. Они не публикуются в
этом репозитории. Получите их из полной конкурсной сборки по ссылке выше.

## 5 Запуск

После размещения весов в каталоге `models`:

```powershell
.\run_submission.cmd C:\plates C:\result.csv
```

Либо:

```powershell
.\.venv\Scripts\python.exe predict.py `
  --input C:\plates --output C:\result.csv `
  --models models --settings settings_submission.json `
  --ocr-checkpoint models\fine_tuned\easyocr_autoria_mixed_20260930_from_step1000_step1000.pt `
  --format-mode strict
```

В `examples` находятся три процедурные демонстрационные карточки без
персональных данных.

## 6 Формат CSV

```text
image;plate_num;plate_type;confidence
car_001.jpg;A123BC77;type1;0.950000
```

Несколько номеров на одном кадре дают несколько строк. Для кадров без
результата строки не записываются.

## 7 Обучение и данные

Генератор находится в `generator`. Скрипты подготовки и дообучения EasyOCR
находятся в `tools`. Для mixed fine-tune использовались корректная синтетика
и OCR-кропы [AUTO.RIA Numberplate OCR Dataset](https://huggingface.co/datasets/AY000554/Car_plate_OCR_dataset).
Сведения о лицензии, контрольных суммах архивов и параметрах запуска описаны
в `docs/DATA_AND_TRAINING.md`.

Полный датасет и веса намеренно не включены: это уменьшает репозиторий и не
публикует фотографии либо OCR-кропы сторонних источников.

## 8 Результаты

| Набор | Результат |
|---|---|
| Official public debug | 81/115, score 74.65, precision 83.51% |
| AUTO.RIA test | 2163/2845, exact 76.03%, CER 0.161899 |
| Synthetic validation | exact 76.6%, CER 0.04444 |
| Development input_images | 13/15 |
| Development two_line | 16/19 |

Official public debug открыт и не является независимым тестом. AUTO.RIA test
содержит OCR-кропы, а не полные сцены автомобиля. Эти показатели не являются
гарантией результата на скрытом наборе.
